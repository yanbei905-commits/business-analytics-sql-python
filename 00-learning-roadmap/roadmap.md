| 阶段 | 内容 | 建议时长 | 产出 |

## 阶段 1：SQL 基础（商业分析视角）

### 核心技能
- SELECT、WHERE、ORDER BY、LIMIT
- 聚合：COUNT、SUM、AVG、MAX、MIN
- GROUP BY + HAVING
- JOIN（INNER / LEFT / RIGHT）
- 子查询与 CTE（WITH）
- 窗口函数（ROW_NUMBER、RANK、LAG/LEAD、SUM OVER）

### 业务指标练习重点
- 销售额 / 订单量 / 客单价
- 复购率、留存粗略计算
- 品类/门店/时间维度对比
- 同比增长（YoY）、环比（MoM）

### 推荐资源
- 本仓库 `01-sql/`
- Mode SQL Tutorial / SQLBolt（免费）
- 《SQL必知必会》

### 检查点
能独立写出：某月各品类销售额排名 + 占比 + 同比的查询。

---

## 阶段 2：Python 基础 + Pandas for Business

### 核心技能
- Python 基础语法（变量、列表、字典、函数、条件与循环）
- Pandas：读 CSV/Excel、筛选、分组聚合、合并、缺失值处理
- 数据类型转换、时间处理
- 用 Pandas 实现和 SQL 一样的逻辑

### 商业分析常用操作
- 数据清洗（缺失、异常、重复）
- 特征构造（客单价、购买间隔等）
- 分组汇总与透视表
- 简单 RFM 分析

### 推荐资源
- 本仓库 `02-python/`
- Pandas 官方文档 + 《利用Python进行数据分析》
- Kaggle Learn (Pandas)

### 检查点
能用 Pandas 完成：读取销售数据 → 清洗 → 计算各渠道/品类核心 KPI → 输出表格。

---

## 阶段 3：SQL + Python 整合

### 核心技能
- 使用 `sqlite3` 或 `SQLAlchemy` 连接数据库
- 用 Python 执行 SQL、把结果变成 DataFrame
- 把分析结果写回数据库或导出报告
- 简单自动化脚本（定时跑指标）

### 检查点
写一个脚本：连接示例数据库 → 跑几条业务 SQL → 用 Pandas 做二次分析 → 生成图表。

---

## 阶段 4：可视化与业务报告

### 工具
- Matplotlib + Seaborn（基础）
- 可选：Plotly（交互）

### 重点
- 选择合适图表（趋势用折线、对比用柱状、构成用饼/堆叠）
- 标题、轴标签、单位、结论清晰
- 写「洞察 + 建议」，而不是只展示数字

## 阶段 5：项目作品集（最重要）

建议至少完成 3 个项目：

1. **业务落地型**：销售仪表盘 / 品类分析 / 门店对比
2. **客户分析型**：RFM 客户分群 + 运营建议
3. **科研风格**：提出明确研究问题，做严谨描述性/探索性分析，写出结构化报告

每个项目必须包含：
- 清晰的业务/研究问题
- 数据来源与处理说明
- 分析方法
- 可视化结果
- 结论与可执行建议
- 代码可复现（放在本仓库对应目录）

```bash
pip install pandas numpy matplotlib seaborn sqlalchemy jupyter openpyxl
```

## 学习原则（针对你的背景）

1. **永远带着业务问题学**：不要只背语法，每次都问「这个能帮我回答什么业务问题？」
2. **SQL 和 Python 交叉练**：同一指标先用 SQL 算，再用 Pandas 算，对比理解。
3. **尽早做项目**：不要等「学完再做」，边学边产出。
4. **记录过程**：在仓库里用 Markdown 写学习笔记和项目 README，这本身就是作品。
5. **为申研和就业准备**：项目描述用英文+中文双语更好，突出问题定义、方法、洞察。

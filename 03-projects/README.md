# 商业分析项目作品集

这里放你完成的完整项目。每个项目建议单独建文件夹，并包含：

```
project-xx-name/
├── README.md          # 项目说明（问题、方法、结论）——最重要
├── data/              # 原始或处理后的数据（注意隐私）
├── sql/               # 用到的 SQL 查询
├── notebooks/         # Jupyter 分析过程（可选）
├── scripts/           # 可复现脚本
└── outputs/           # 图表、报告 PDF 等
```

## 推荐项目方向（适合工商管理背景 + 申研/就业）

### 项目 1：零售销售分析仪表盘（业务落地型）
- 问题：各门店/品类/时间维度的销售表现如何？哪些值得重点关注？
- 技能：SQL 聚合 + Pandas + 可视化
- 产出：月度趋势图、门店对比、品类贡献、简单建议

### 项目 2：客户 RFM 分群与运营建议（客户分析型）
- 问题：如何识别高价值客户、流失风险客户？对应运营动作是什么？
- 技能：SQL/Python 计算 R/F/M，分群，解读
- 产出：客户分群表 + 每组特征描述 + 可执行建议

### 项目 3：带研究问题的探索性分析（科研风格）
- 问题示例：「不同年龄段客户在品类偏好上是否存在显著差异？」「线上与线下客单价差异的可能原因是什么？」
- 技能：清晰问题定义、描述性统计、分组对比、谨慎下结论
- 产出：结构化分析报告（适合写进 SOP / 研究兴趣）
